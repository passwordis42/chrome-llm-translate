# 一翻（Chrome 扩展） · 需求文档（2026-11-03·医生已确认 Sure）

> v0.1.1（2026-11-03 整页落地）：整页 AI 改为原网页段落下插译文，去掉盖层对照页。整页谷歌只唤起浏览器原页翻译，不跳转 translate.google.com。

## 目标
Chrome 自带翻译不够准；用千问等 LLM 做精准翻译（划词 / 整页），不重要的整页仍可手动走谷歌自带翻译。进页不自动翻译。

## 产品定位
- 平台：**仅 Chrome**（Manifest V3 扩展）
- 模型：阿里云 **通义千问** API（医生自备 Key；与一声创作日历同源用法）
- 语言：源/目标可切换，覆盖主流语种（以模型支持为准）

## 三种翻译方式
1. **划词翻译**（默认开启）  
   - 选中文本 → **浮层双语对照**（原文 + 译文）  
   - 可关；支持流式输出；可一键复制译文  
2. **整页 AI 翻译**（须医生确认才跑）  
   - 工具栏/右键/弹窗点「整页 AI 翻」并确认  
   - **文内并排双语**（按段落原文 | 译文）  
   - 流式输出；可一键复制  
3. **整页谷歌翻译**（须确认；用于「不重要」的整页）  
   - 确认后唤起 Chrome 自带整页翻译  
   - **不做** LLM 双语卡  

「不重要」= 整页粒度，由医生手动选走谷歌还是 AI，**不做**自动识别、**不做**站点黑白名单。

## v1 功能范围
**做：**
- 划词浮层双语、整页 AI 文内并排、整页谷歌唤起（均确认策略如上）
- 设置：API Key、源/目标语言、划词开关
- 术语本（固定译法优先）
- 一键复制译文
- 流式输出
- 右键菜单入口（划词 / 整页 AI / 整页谷歌）

**不做：**
- 翻译历史
- 站点黑白名单
- Edge / Firefox
- 进页自动翻译
- 自建后端（Key 存扩展本地；直连千问）

## UI
- 划词：浮层（UI 小样 A）
- 整页 AI：文内并排（UI 小样 B）
- 设置页、确认对话框、右键菜单
- 出正式稿给医生审后再嵌

## 验收标准（摘要）
1. 进页无任何自动翻译  
2. 划词默认开，浮层双语；关闭后不弹  
3. 整页 AI / 整页谷歌均须二次确认；取消无副作用  
4. 整页 AI 为文内并排双语；谷歌为浏览器自带行为  
5. 术语本命中优先；复制可用；流式可见逐字/逐段出现  
6. 右键三项均可达；无效 Key / 网络失败有明确提示、不假翻  
7. 仅 Chrome；交付安装包/加载说明经 GitHub（医生自行加载）
